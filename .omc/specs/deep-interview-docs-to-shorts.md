## Goal
개발자용 기술 문서(라이브러리/API 문서 URL 또는 Markdown 파일) 하나를 입력하면, AI가 장면별 한국어 숏폼 대본을 만들고, 사용자가 로컬 웹 UI에서 검토·수정·승인한 뒤, AI 배경 이미지 위에 원문 코드를 정확히 얹은 30~60초 9:16 영상(한국어 TTS + 자막)을 렌더링해 유튜브 쇼츠에 비공개로 업로드하는 개인용 프로그램.

## Constraints
- 입력: 기술 문서 URL 1개 또는 로컬 Markdown 파일 1개 → 영상 1편.
- 사람 개입: AI 대본 초안 → **사람 검토·승인 필수** → 렌더링. 승인 없이 렌더/업로드하지 않음.
- 인터페이스: 내 PC에서 실행하는 **로컬 웹 UI**(localhost). 로그인·DB·호스팅 없음, 단일 사용자.
- 언어: 내레이션·자막은 **한국어**. 코드, API 이름, 기술 용어는 원문 유지.
- 화면 구성: 장면별 **AI 생성 이미지 배경 + 코드/텍스트 오버레이** (말하는 아바타 없음).
- AI 공급자: 대본 = **Claude API**, 배경 이미지·TTS = **OpenAI API**. 공급자는 인터페이스로 분리해 교체 가능하게.
- 비용 목표: 편당 수백 원 수준.
- 영상 규격: 9:16 세로, 30~60초, mp4.
- 배포: YouTube Data API로 **비공개(private)** 업로드. OAuth 인증 필요.
- 환경: Windows 11. (참고: 현재 Node.js 미설치. 스택은 계획 단계에서 결정)

## Non-Goals
- 말하는 아바타 / AI 생성 동영상
- 틱톡·릴스 등 유튜브 외 플랫폼 업로드
- 공개/예약 공개 자동화
- 한 문서 → 여러 편 시리즈 분할
- 다중 사용자, 로그인, 클라우드 배포
- 영어 등 다국어 내레이션
- PDF/Word/Notion/Google Docs 입력

## Acceptance Criteria
- [ ] AC-1: 기술 문서 URL을 입력하면 본문 텍스트와 코드 블록이 분리 추출된다.
- [ ] AC-2: 로컬 Markdown 파일을 입력해도 같은 결과가 나온다.
- [ ] AC-3: Claude가 장면 목록(장면별 내레이션, 화면 텍스트, 사용할 코드 블록 참조, 이미지 프롬프트)을 생성하며, 총 내레이션 분량은 30~60초를 목표로 한다.
- [ ] AC-4: 로컬 웹 UI에서 장면별 내레이션·화면 텍스트·이미지 프롬프트를 수정하고, 장면별 배경 이미지를 재생성할 수 있다.
- [ ] AC-5: 사용자가 "승인"하기 전에는 렌더링·업로드가 실행되지 않는다.
- [ ] AC-6: 출력은 1080×1920 (9:16) mp4이며 길이가 30~60초다.
- [ ] AC-7: 영상에 표시된 코드는 원문 문서의 코드와 **글자 하나 틀리지 않는다** (코드는 LLM이 다시 쓰지 않고 원문에서 참조로 가져온다).
- [ ] AC-8: 각 장면은 AI 배경 이미지 + 코드/텍스트 오버레이 + 한국어 TTS 음성 + 음성과 동기화된 한국어 자막을 포함한다.
- [ ] AC-9: Claude/OpenAI 호출은 공급자 인터페이스 뒤에 있어, 구현체 교체로 다른 공급자를 쓸 수 있다.
- [ ] AC-10: mp4와 메타데이터(제목·설명·해시태그)가 로컬 출력 폴더에 저장된다.
- [ ] AC-11: 업로드 버튼을 누르면 YouTube Data API로 쇼츠가 **비공개** 업로드되고, 결과 영상 URL이 UI에 표시된다.
